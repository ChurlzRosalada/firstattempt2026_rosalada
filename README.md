# Santos

**Framework:** Vue.js 3 (Vite)
**Module:** Web Systems / Application Development

---

## About

AdDU Alumni — a web application for the Ateneo de Davao University alumni community. Built with Vue 3, Vue Router, and Vite. Features include alumni verification, directory, mentorship hub, events management, personalized calendar, and more.

---

## Installation

Follow these steps to run the project on a different computer:

### Prerequisites
- [Node.js](https://nodejs.org/) v18 or higher
- npm (comes with Node.js)

### Steps

```bash
# 1. Clone the repository
git clone https://github.com/<your-username>/firstattempt2026_lastname.git

# 2. Navigate into the project folder
cd firstattempt2026_lastname

# 3. Install dependencies
npm install

# 4. Start the development server
npm run dev

# 5. Open your browser and visit
# http://localhost:5173
```

### Build for Production

```bash
npm run build
npm run preview
```
